峠のチーズタルト｜イベント販売管理 v6

今回の主な修正
1. イベント期間と販売日の日本時間の1日ズレを修正。
2. 在庫管理を「初回搬入→ショーケース」「追加搬入→ストッカー」「販売→ショーケースから減る」に変更。
3. ストッカーを減らした数量はショーケースへ自動移動。総在庫はショーケース＋ストッカー。
4. 在庫画面を全商品一括保存に変更。
5. 日報印刷タイトルを「部門別売上日報（スイーツ工房イベント用）」に変更。
6. Firebaseクラウド同期の準備機能を含む（firebase-config.jsに設定が必要）。

Firebase設定は、ユーザーのFirebase ConsoleでWebアプリ登録後に発行されたクライアント設定値をfirebase-config.jsへ入れてください。
サービスアカウントの秘密鍵は入れないでください。

GitHub PagesのURLは変更する必要ありません。
